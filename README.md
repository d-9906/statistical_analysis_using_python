# Statistical Analysis of Government Open Data Using Python

## Overview
This project performs statistical analysis on publicly available government open data using Python. The objective is to clean, analyze, visualize, and interpret the dataset to identify meaningful trends and insights.

## Objectives
- Statistical Analysis
- Data Visualization
- Insight Generation

## Technologies Used
- Python
- Pandas
- NumPy
- Scipy
- ChartGo
- Excel

## Dataset
Government Open Data Dataset

## Features
- Statistical summaries
- Charts and visualizations
- Excel-based analysis
- Final report and presentation

## Results
The analysis identified key patterns and trends within the dataset and presented the findings using charts and statistical summaries.
