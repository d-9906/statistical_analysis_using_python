# Statistical Analysis of Government Open Data Using Python

## Overview
This project performs statistical analysis on publicly available government open data using Python. The objective is to apply common statistical methods on the data to identify meaningful trends and insights.

## Objectives
- Statistical Analysis
- Data Visualization
- Insight Generation

## Technologies Used
- Python
- Pandas
- NumPy
- Scipy
- ChartGo
- Excel

## Dataset
Government Open Data Datasets- 

###City, Age Group and Gender-wise Persons Arrested under IPC Crimes in Metropolitan Cities during 2019.  
VARIABLES USED FOR ANALYSIS: 
1.Total male arrested    2.Total female arrested    3. Total persons arrested 

###Crime Head-wise Police Disposal of IPC Crime Cases during 2019. 
VARIABLES USED FOR ANALYSIS: 
1.Total cases reported during the year    2.Total cases disposed off during the year

## Features
- Statistical summaries
- Charts and visualizations
- Excel-based analysis
- Final report and presentation

## Results
The analysis identified key patterns and trends within the dataset and presented the findings using charts and statistical summaries.
